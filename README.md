# Cartilha digital — Rota Segura

Cartilha educativa e interativa sobre direitos, proteção previdenciária, seguros, segurança no trânsito e condições de trabalho de entregadores por aplicativo.

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra `index.html` em um navegador atualizado.
3. Para publicar, envie os três arquivos (`index.html`, `style.css` e `script.js`) para um serviço de hospedagem estática, como GitHub Pages, Netlify ou Vercel.

## Personalização antes de publicar
- Edite o crédito no final da página e informe instituição, equipe, curso e contatos do projeto.
- Revise os dados estatísticos e inclua a referência completa do relatório utilizado pela equipe.
- Dados estatísticos atualizados com a PNAD Contínua 2025, divulgada em 2026. Confira eventuais atualizações legislativas e administrativas na data da apresentação.
- O botão de compartilhar usa o recurso nativo do navegador quando disponível. O quiz, busca e perguntas expansíveis funcionam sem servidor.
